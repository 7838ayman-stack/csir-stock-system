# CSIR Canteen Stock Management System

A full-stack web application built to manage canteen inventory, track stock levels, and log stock history changes in real-time.

## 🚀 Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MySQL

## ✨ Features
* Admin Authentication & Route Protection
* Real-time Stock Tracking (Increase/Decrease)
* Low Stock Alerts (Threshold < 5)
* Stock History Logs with Date Filtering
